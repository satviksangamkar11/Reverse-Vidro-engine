## Four analysis levels, relationships kept
VIDEO (narrative progression, opening, pacing, ending) > SEQUENCE (setup-anticipation-reveal-reaction-payoff) > SHOT (composition, movement, performance, light, sound, transition) > TECHNIQUE (purpose, evidence, reproduction, limits, when NOT to use)

## Mandatory questions per meaningful beat
what information; how revealed visually; why these shots combined; what the character does; how camera guides attention; how transitions connect; sound/silence vs image; which animation principles; which VFX; which assets/controls reproduce it; what GranthStudio can do now; which gaps need NEED_NEW; which techniques are inappropriate for our production style. Creative intention = hypothesis only.

## Evidence kept per finding
video id + source URL; exact timestamps + evidence frames; observed visual/audio facts; terminology; inferred purpose; possible mechanism; alternative explanations; confidence + verification status; applicability to GranthStudio; failure cases/contraindications. Never infer editing software, lenses, hidden rigs, or screenplay text. Frame-only ZIPs get no fabricated audio findings.
