# SPEC FC13E: NEW `pieces/fc13_eval.py` and `pieces/test_fc13_eval.py` (Fast-Close V1.3: frozen, blinded A/B evaluation protocol)

GOAL: freeze, before any director call, how the six A/B scene plans (scenes S3, S6, S8; arm A = baseline, arm B = with lessons) will be measured. Two separate families: COMPLIANCE (did the plan follow the five lessons; descriptive counts only) and DIRECTING QUALITY (deterministic validator facts plus a blinded 1-5 rating). The decision uses quality only, is symmetric between arms, and never assumes arm B is better. The module writes the frozen protocol, a blinding key and an empty blinded rating sheet. It makes no model call.

REAL FACTS (verified 2026-11-01 against the real files):
- Snapshot folder (read only): `work/phase1/departments_16/fastclose_v13/inputs/` with `presets/index.json` (JSON list of 11 dicts, key `preset`), eleven `presets/<preset_id>.json`, `A1_timing_plan.json`, `sample_scene_result_S4.json`, `SNAPSHOT_MANIFEST.json`.
- Preset zoom: start `segments[0]["camera"]["start"]["zoom"]`, end `segments[-1]["camera"]["end"]["zoom"]`; gain = end minus start, rounded to 2 decimals. Real gains: 01_establishing_shot 0.28, 02_environmental_parallax 0.13, 03_slow_cinematic_push 0.20, 04_character_entrance 0.14, 05_bowing_prayer 0.14, 06_blessing_gesture 0.30, 07_character_reaction 0.14, 08_emotional_closeup 0.25, 09_dialogue_composition 0.13, 10_object_hand_insert 0.14, 11_scene_transition 0.00.
- `A1_timing_plan.json`: key `scenes` is a list of dicts with `scene` (e.g. "S3") and `shots`, a list of dicts with `shot` (1-based int) and `lines_starting` (list). A shot with an empty `lines_starting` is VISUAL-ONLY. Real values: S3 -> [6]; S6 -> [5, 6]; S8 -> [5].
- A director scene result (the file the director writes, e.g. `a01_scene3.json`; shape as in `sample_scene_result_S4.json`) has keys `scene`, `result` (e.g. "VALID", "INVALID", "UNRESOLVED"), `errors` (list of str), `warnings` (list of str), `plan` (dict or null). `plan` has `goal`, `turn` ({"ovi": "A1:112", "text": ...}), `shots` (list), `images_needed` (list). A shot has `shot_id`, `ovi_ids` (list of "A1:n"), `preset`, `action`, `held_pose`, `performance`, `camera`, `dialogue` (list of dicts with `meaning_en`), `claims` (list of {"kind", "term", "source"}), `staging` (list of str), `transition_out`.
- The `result`, `errors` and `warnings` fields are ALREADY the output of the consumer's own deterministic validator (schema, quoting, provenance, preset roles). This module reads them; it never re-validates or changes them.
- Expected values on `sample_scene_result_S4.json` (independent hand count; hardcode in the test): presets in order 01_establishing_shot, 02_environmental_parallax, 03_slow_cinematic_push, 08_emotional_closeup, 03_slow_cinematic_push; all transitions "cut"; turn ovi "A1:112"; result "VALID"; 0 errors; 3 warnings, all 3 containing "STAGING"; 9 images_needed.

CONSTANTS: ROOT = repository root; INPUTS = ROOT/work/phase1/departments_16/fastclose_v13/inputs; OUT_DIR = ROOT/work/phase1/departments_16/fastclose_v13; SCENES = ("S3", "S6", "S8"); ARMS = ("A", "B"); TRANSITIONS = ("cut", "slide", "pan_bridge"); CLOSEUPS = ("07_character_reaction", "08_emotional_closeup", "10_object_hand_insert"); FLAT_OK = ("03_slow_cinematic_push", "10_object_hand_insert", "11_scene_transition") (presets the flat final images can feed, per the consumer's own architecture review); STRONG = 0.20; OVI_REF = regex `^A[0-9]+:[0-9]+$` (raw string).

FUNCTIONS (standard library only: json, re, hashlib, csv, os, pathlib, secrets, sys):
- load_gains(inputs_dir) -> dict preset_id -> gain (from the files as above). Raise ValueError unless exactly 11 presets.
- visual_only(timing, scene) -> list of 1-based shot numbers whose lines_starting is empty. Raise ValueError for an unknown scene.
- compliance(result, gains, visual_only_shots) -> dict. If `plan` is not a dict or `plan["shots"]` is not a non-empty list, return {"computable": False, "reason": "no plan"} (an invalid output is recorded, never dropped). Otherwise {"computable": True} plus:
  - C1_opening: {"first_preset": shots[0]["preset"], "first_shot_source_cited": True if shot 1 has a claim of kind person, event, prop or scenery whose source matches OVI_REF}.
  - C2_camera: {"shots": n, "distinct_presets": count, "same_preset_consecutive_pairs": count of i with preset i == preset i+1, "strong_consecutive_pairs": count of i where both presets have gain >= STRONG (unknown presets count as not strong)}.
  - C3_reaction: {"turn_ovi": plan turn ovi, "turn_shot_has_ovi_pose": True if some shot whose ovi_ids contains the turn ovi has a claim of kind "pose" whose source matches OVI_REF, "narrator_mentions": count of shots whose performance contains "narrat" (case-insensitive)}.
  - C4_progression: {"invalid_transitions": count of transition_out not in TRANSITIONS, "unknown_presets": count of presets neither in gains nor equal to "NEED_NEW", "need_new": count equal to "NEED_NEW", "closeup_on_turn": True if a shot with a CLOSEUPS preset has the turn ovi in its ovi_ids}.
  - C5_quiet: {"visual_only_gains": [gain of each listed shot number that exists in the plan, None for an unknown preset], "quiet_strong_pushes": count of those gains >= STRONG}.
  These are descriptive numbers. The module defines NO pass/fail threshold on them.
- quality_facts(result) -> dict {"validator_result": result["result"], "validator_errors": len(errors), "warnings": len(warnings), "staging_warnings": count of warnings containing "STAGING", "need_new": count of NEED_NEW shots (0 if no plan), "flat_compatible_share": round(share of shots in FLAT_OK, 3) or None if no plan, "images_needed": len or 0}.
- make_key(seed) -> dict scene -> {"A": label, "B": label} with labels "P1"/"P2": arm A gets "P1" when the first byte of sha256((seed + "|" + scene).encode()) is even, else "P2"; arm B gets the other label. anon_id(seed, scene, arm) -> "X" + the first 7 hex characters of sha256((seed + "|" + scene + "|" + arm).encode()).
- blinded_view(result) -> (text, risks). text shows only: the plan goal, the turn text, then each shot renumbered "shot 1", "shot 2", ... with preset, ovi_ids, action, held_pose, performance, camera, staging, transition_out and each dialogue meaning_en. No run name, model name, call record, review, cost or arm. If there is no plan: "NO VALID PLAN (experimental failure). Validator: <result>; first errors: <up to 3 errors>". risks = the sorted list of words among ("lesson", "experimental", "baseline", "assisted") found in text, case-insensitive (reported, never edited out).
- RUBRIC: a module-level list of six dicts {"id", "name", "question", "anchor_1", "anchor_3", "anchor_5"}: Q1 narrative clarity (can a viewer follow what happens and why?), Q2 emotional communication (is the stated feeling conveyed without invention?), Q3 visual storytelling (do the pictures carry the scene, not only the narration?), Q4 shot progression (does the order of framings and transitions clarify events, reactions, reveals and space?), Q5 canon fidelity (nothing beyond the ovis and PACKET; every claim sourced), Q6 production feasibility (buildable with the registered presets and flat final images). Write short anchors in plain words.
- sheet_rows(key, seed) -> list of dict rows, one per scene and label, ordered by scene then label: scene, label, anon_id (of the arm behind that label), Q1..Q6 (empty), preference (empty; allowed values P1, P2, TIE), notes (empty). No arm column.
- decide(ratings, key, facts) -> dict. ratings: scene -> {"P1": {Q1..Q6 ints}, "P2": {...}, "preference": "P1"|"P2"|"TIE"}. facts: scene -> arm -> quality_facts dict. For each scene: map labels to arms with key; the preferred arm WINS the scene only if (a) its total of Q1..Q6 is >= the other arm's total, (b) its Q5 is >= the other arm's Q5, and (c) its validator_errors is <= the other arm's; otherwise the scene is a TIE (TIE preference is a TIE). Verdict: "B_BETTER" if B wins at least 2 scenes, "A_BETTER" if A wins at least 2 scenes, else "NO_CLEAR_DIFFERENCE". Return {"per_scene": scene -> "A"|"B"|"TIE", "verdict": verdict}. Compliance is NOT an input of decide.
- protocol(root) -> dict {"schema": 1, "name": "FASTCLOSE_V13_EVAL_PROTOCOL", "scenes": SCENES, "arms": {"A": "baseline", "B": "baseline plus the five experimental director lessons"}, "compliance_definitions": short text per C1..C5, "quality_deterministic": list of quality_facts keys, "rubric": RUBRIC, "decision_rule": one paragraph that restates decide in words and says compliance never decides, "visual_only": {scene: visual_only(...)}, "code_sha256": sha256 of the bytes of this module file, "snapshot_manifest_sha256": sha256 of INPUTS/SNAPSHOT_MANIFEST.json}. Add "protocol_sha256" = sha256 of json.dumps(the dict without that key, sort_keys=True, ensure_ascii=False).
- main(argv=None) -> int: write OUT_DIR/EVAL_PROTOCOL.json. If OUT_DIR/BLINDING_KEY.json does not exist, create a seed with secrets.token_hex(16) and write {"seed": seed, "key": make_key(seed), "anon_ids": {scene: {arm: anon_id}}}; if it exists, read it and never overwrite it. Write OUT_DIR/BLINDED_SHEET_TEMPLATE.csv from sheet_rows. Print the protocol_sha256. Return 0.
